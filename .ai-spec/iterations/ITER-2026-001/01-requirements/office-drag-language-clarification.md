## 需求摘要

办公室画布增加手动拖拽平移能力，并提供中文 / English 界面切换。该变更只影响前端交互和产品 UI 文案，不改变工作区业务事实、持久化模型或外部 CLI 协议。

## In-scope

- 鼠标左键拖拽办公室空白区域平移视口。
- 触摸单指拖拽继续平移，双指缩放继续可用。
- 成员精灵点击继续选中；成员区域拖动不触发视口平移。
- 空白区域短点击继续清除选中。
- 工具栏、任务、设置、Inspector、页脚、运行状态和办公室反馈支持中文 / English。
- 语言偏好写入浏览器 `localStorage`，刷新后保持。

## Out-of-scope

- 不拖拽修改员工座位、任务、房间或任何工作区业务事实。
- 不自动翻译用户创建的任务标题、描述、员工姓名、项目名称或文档内容。
- 不翻译历史文档、外部 CLI 输出和 M1 视觉资源源文件。
- 不新增第三方依赖，不修改 API / SQLite 契约。

## 功能验收标准

| ID | 验收标准 |
|---|---|
| BB-UI-01 | 空白区域拖拽后相机 scroll 坐标发生变化，且没有业务 POST / workspace 写入。 |
| BB-UI-02 | 成员区域短点击仍选中成员；成员区域拖动超过阈值不改变已有选择。 |
| BB-UI-03 | 空白区域短点击清除当前选择。 |
| BB-UI-04 | 切换 English 后办公室提示、导航、状态、任务、设置、Inspector 和页脚使用英文资源。 |
| BB-UI-05 | 刷新后语言偏好保持；业务实体名称与用户内容保持原文。 |
| BB-UI-06 | 触摸单指平移、双指缩放、演示模式和既有成员移动流程不回归。 |

## NFR

- 不新增网络请求；画布拖拽为本地相机状态变化。
- 不写入 workspace snapshot、SQLite 或业务审计。
- 语言切换不改变业务数据和选择状态。
- 交互控件保持键盘可达，移动端保持既有最小触控尺寸。
- 资源加载失败、上下文丢失和路径反馈在当前语言下可读。
