## 验收环境

M1 使用本地正式构建、前台可见的 Chromium 浏览器测试。记录 OS、CPU、GPU、内存、浏览器完整版本、Node、Phaser、EasyStar、构建/资源/fixture hash、电源模式、刷新率、CSS viewport 与 DPR。测试数据来自显式临时 Store 和合成快照，禁止把真实工作区作为 fixture；场景操作不得写回业务快照或磁盘。

## 验收标准

| ID | NFR | 指标与阈值 | 环境与数据规模 | 度量方式 | 负责人 |
|---|---|---|---|---|---|
| NFR-M1-01 | 帧预算 | 目标 60fps；每个 run 的帧间隔 P95 <=20ms、P99 <=33ms | 1440x900，DPR1/2；32x24 地图；20 人、8 人持续移动、5 个详细气泡 | 每个 DPR 预热 30 秒、采样 60 秒、独立 3 次；保留逐 run 样本、均值、标准差、分位数与 trace | QA |
| NFR-M1-02 | 交互响应 | 选择、缩放、面板反馈 P95 <=100ms；串行本地非模型命令用户端 P95 <=300ms | 200 个任务；四个候选尺寸；每类动作至少 30 次 | 浏览器输入时间到对应 DOM/Canvas 可见帧；命令另记 dispatch、网络和确认快照时间 | QA |
| NFR-M1-03 | 加载与离线 | 冷缓存首屏可操作 <=3s；非 loopback 外部请求为 0 | 三个新浏览器 context；禁 cache、清 Service Worker；已有合成工作区 | navigationStart 到合法快照、地图、人物和关键控件可操作；每个 run 独立判定 | QA |
| NFR-M1-04 | 可读与可达 | 普通文字对比度 >=4.5:1；无互遮、裁切或不可达主操作；手机目标 >=44px | 390x844、1024x768、1366x768、1920x1080，DPR1/2；长中文、长 ID、抽屉/底栏/菜单打开态 | 截图、DOM bounds、真实多点命中、键盘流程、Canvas ROI、动作帧和前后遮挡像素证据 | QA + 视觉复审 |
| NFR-M1-05 | 稳定性 | 第 10 至 30 分钟强制 GC 后 heap 增长 <=20%；监听器、canvas、root 行为不持续增长或倍增 | 20 人、8 人持续移动、5 气泡；DPR1/2 各 30 分钟；详情均匀开关 100 次 | 10/20/30 分钟统一 GC 样本；记录 heap、监听器、canvas、资源趋势、重复进入退出与双 root 行为 | QA |
| NFR-M1-06 | 数据隔离与安全 | 跨实例影响、默认存储打开、场景 POST、脚本执行、意外外联、伪审批均为 0 | W01 四轮隔离、W02 安全/保存故障、W03 队列/root、M1 场景回归 | 临时 Store 守卫、请求审计、恶意文本、无效命令、完整快照/hash 对照 | QA + 安全复审 |

分位数统一采用 nearest-rank。任一 run 超阈值即失败，不允许把多个 run 合并平均后判定通过。M1 无旧性能基线，本次正式运行建立首个可复现基线并回写测试知识库。

## 不适用与替代验证

100 人多楼层、真实模型运行、真实会议编排、上传/解析/索引、工具授权、SQLite 迁移和 WebSocket 断线重放不属于首批范围。M1 以 20 人合成场景、W03 unknown 写屏障、临时 JSON 恢复和本地预演零业务写入验证当前边界；这些替代验证不代表未来能力已完成。
