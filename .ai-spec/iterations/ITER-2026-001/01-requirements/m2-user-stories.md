| M2-02 | 管理员可配置 Agent runtime 和工程目录 | profile ID 与 workspace 解耦；路径越界、只读目录、未登记 executable 均被拒绝。 |

| M2-05 | 用户可审批、取消、超时和重试任务 | manual run 必须 waiting；审批后才能执行；取消/超时不伪造成功；重试产生新 run 并保留 retryOf。 |
| M2-06 | 用户可查看任务产物并追溯 | artifact 仅位于 run 专属目录；任务、run、文档和审计事件通过 correlationId 关联；敏感输出脱敏。 |
| M2-07 | 用户刷新、重启或断线后可继续工作 | 已确认写入可恢复；事件游标可补快照；重复命令不产生重复副作用；离线写操作被禁用。 |
| M2-08 | 画布与任务状态保持一致 | 画布只消费服务端确认的状态投影；动画不能直接改变任务、run 或审批事实。 |

## Out of scope

- 真实多 Agent 会议、Moderator、Leader 拆解。
- 文件上传/解析、向量索引、记忆抽取。
- 多团队、多楼层、桌面打包。
- 复杂模型用量计费和跨租户权限。
