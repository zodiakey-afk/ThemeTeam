## DR-01 Operations
Machine-readable route schemas/defaults in w02-routes-v1.1.json. Snapshot schema unchanged from models.py / first-batch compatibility; no fields migrated. Null only moderatorId. Empty text legal, no trimming; empty IDs must resolve or return404. Unknown fields rejection is an intentional compatibility change for invalid inputs. Strict scalar types, bool not number, unique lists, moderator must be participant when nonnull. Missing body required field400; unknown entity404; enum400; locked destination409. category/source/role free text. Limits count Unicode code points. Public Store methods use the same validation; aliases delegate. close_meeting is a record-only close: validate id/summary/task refs before updating, no archive side effects. set_theme_and_save runs under the same reentrant operation lock.

## DR-02 Atomicity
One reentrant Store lock held for ENTIRE save/reload/mutation, including validation, candidate construction, I/O and publication; snapshot acquires it too. One Store per storage path; independent same-path writers unsupported. Save copies live state, prepares timestamp/event/response and strict JSON, writes a unique sibling temp, flush/fsync, os.replace, then a single assignment publishes the prebuilt candidate. No fallible preparation after replace. Replace is commit point: precommit failure leaves disk/live unchanged and cleans owned temp; crash after replace may commit new valid data. No power-loss durability claim. Reload holds lock while loading, constructing candidate+response and assigning. Explicit reload discards earlier unsaved changes, never later ordered mutations. Archive constructs complete doc/memory/meeting/event candidate via deepcopy before one assignment. Deterministic barrier tests verify save/save, save/mutation, reload/mutation and save/reload serialize. Serialization/write/fsync/replace fault injection all before commit; restart sees valid old or committed file.

## DR-03 Archive table
Candidate docs: category exactly meeting-notes AND (sourceRef equals meeting.id OR linkedMeetingIds contains meeting.id). Zero -> new archive (ignore seeded architecture doc). Multiple ->409. One -> require sourceRef equals meeting.id AND linkedMeetingIds either [] or [meeting.id], else409 unchanged. Requested summary exact equality to doc.content, and to meeting.summary if already closed, before repair; omitted summary defaults empty. Memory candidates: sourceType meeting AND linkedDocs contains archive doc.id. Multiple ->409; one requires text equals doc.content AND linkedDocs == [doc.id], else409. Zero -> create unapproved memory. Historical approval flags preserved. Missing meeting backlink/document link repaired only on explicit successful close; retain unrelated linked docs. Complete replay leaves all state/events unchanged. Response stays snapshot, repaired links observable, no new flags. Concurrent repairs serialize. All conflicts checked before publication, no partial repairs.

## DR-04 Trust/parser
Threats: hostile browser website, malformed local client, persisted hostile strings. Same-user hostile filesystem writer/local process excluded from authentication guarantees. Factory accepts 127.0.0.1/localhost only; ::1 unsupported by existing AF_INET, rejected along with remote bind. Every GET/HEAD/POST validates exactly one Host equal to 127.0.0.1:<actual port> or localhost:<actual port>; missing/duplicate/malformed/foreign ->403. Origin absent allowed for compatible JSON clients; present once must exactly equal http://<Host>; foreign/null/duplicate ->403. No CORS. POST media type application/json with optional charset=utf-8, otherwise400. Missing length means zero; negative/nondecimal/duplicate Content-Length or any Transfer-Encoding400; >1MiB413. Connection timeout5s/close, truncated/slow body400 where writable. Depth>32, duplicates, invalid UTF8 and nonfinite JSON400. GET/HEAD side-effect-free; HEAD same metadata/no body. No authentication product claimed.

## DR-05 Render/static policy
Legacy sinks: phase summaries, document/memory/expansion lists, rooms/teams, room/agent SVG attributes+text, task cards, selection, model options, stats and errors. Dynamic values only in text or double-quoted attributes; escape &,<,>,both quotes. Trusted-fragment wrapper only for already escaped internal SVG fragments. No dynamic raw script/style, events, unquoted attribute, URLs or CSS. Numeric geometry finite/bounded coercion; colors closed hardcoded palette. API IDs URI encoded. Errors textContent. CSP all responses: default-src 'none'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; connect-src 'self'; object-src 'none'; base-uri 'none'; frame-ancestors 'none'; form-action 'self'. Inline style supports existing layout, not inline scripts.
Static exact /,/styles.css,/app.js. Docs root repo/docs: md/txt text/plain UTF8, png image/png, jpg/jpeg image/jpeg, webp image/webp, svg text/plain attachment (never active SVG document). Other extensions denied. Nosniff on all. URL decoded once, NUL rejected, Windows separators canonicalized, resolve then relative_to root, extension checked on resolved path. Outside symlink/junction rejected; concurrent hostile local filesystem replacement out of scope. Existing SVG docs downloadable, legacy generated in-page SVG still works. Browser tests assert no injected nodes/events/network as well as positive controls under CSP.
