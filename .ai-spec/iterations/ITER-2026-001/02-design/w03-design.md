## Data and concurrency
One Zustand vanilla store per browser root, no global persistent selection/camera, no localStorage/BroadcastChannel/API select writes. React subscribes; scene bridge receives the same selected agent ID and snapshot. Snapshot type exactly matches frozen backend contract; validate root entity arrays and required fields at API boundary, treating strings as text, no dangerous HTML. Keep existing state visible with explicit error on failed reload/mutation; server snapshot only published after successful response. Serialize requests (including reload/save) through one queue so older responses never overwrite later results. Mutations not automatically retried, no optimistic fake success. Abort on disposed root, generation guard prevents late publication, no mutation after teardown. Initial empty state has loading/error/retry affordance.

API adapter uses same-origin relative /api only, application/json, timeout10s AbortController, stable backend errors. Development proxy targets 127.0.0.1:configured port and rewrites Host and same-origin Origin to backend authority only after Vite host/origin validation. Vite binds loopback, strictPort true; no wildcard CORS, no LAN. Reject foreign/null Origin before forwarding writes. No proxy target from browser input. Backend remains manual-save: unsaved marker after successful CRUD; clear after save/reload, no implicit save on selection. Disclose manual changes as prototype management, never model execution. No model credential configuration introduced.

## DOM shell and bridge
Compact rail, team/agent directory, task board, selected entity inspector, documents/meetings lists. Normal create Agent/task through validated forms; task status via select, owner button selects Agent; room/meeting/document selections stay in one local discriminated selection. Back closes inspector and restores previous local selection. Search/list handles over-capacity entities without truncation. Stable card grids <=8px radius only for repeated records, flat bands for sections, lucide icon buttons/tooltips, fieldsets/labels, text wrapping, 44px mobile controls. Mobile inspector is a separate grid row/drawer that can close without losing selection; no hero/cards nested. No invented live runtime controls.

Bridge owns one injected scene adapter per mount: adapter exposes update(snapshot,selection) and destroy(); subscribe once, immediate initial update, cleanup unsubscribes+destroys once, disposed bridge ignores late signals. Actual Phaser adapter belongs to W04/M1; W03 interface tests use instrumented adapters, not static bitmap fake scene. Code enables integration without claiming art/map/animation complete.

## Boundary implementation details
Use Ajv8.20.0 (MIT, registry metadata verified) with the frozen 2020-12 workspace snapshot schema rather than a partial handwritten shape validator. Schema bundled locally; no remote $ref fetching, no coercion/default insertion or mutation of responses. TypeScript interfaces map existing schema; root data arrays cannot silently disappear. Versions and audit remain lockfile evidence requirements.
Vite middleware checks exactly one Host equal to localhost:<socket.localPort> or 127.0.0.1:<socket.localPort> on every request. Origin absent accepted for local JSON tools; present once must be http://<Host>, null/foreign403. /api forwarding only after this check. Fixed server environment THEMETEAM_API_PORT defaults8000, integer1..65535; target forced127.0.0.1, never arbitrary URL. Proxy changeOrigin true and rewrites already-validated Origin to http://127.0.0.1:<target-port>. Vite binds127.0.0.1, strictPort true and CORS false. No credentials in bundle or proxy config.
Queue tail absorbs errors only for continued scheduling; each command reports success/failure boolean to form caller, so form closes/resets only on success. pending counts queued+active. Dirty state unaffected by GET load/failure, set true only successful mutation, false only successful save/reload. dispose aborts active request, clears pending and invalidates generation; queued tasks become no-ops and resolve false without fetching. Existing stores/scene adapters are not reused after dispose.

## CR-W03-01 reviewed corrections
contracts/w03-v1.1.json and 05-testing/w03-spec-v1.1.md supersede the preceding boolean-failure, unconditional FIFO and close/back statements. Outcome-unknown writes pause all subsequent writes/save/reload in this session, set uncertain+dirty, and never replay. Read refresh cannot clear uncertainty; operator must independently establish backend quiescence/restart before opening a new session. Teardown guarantees no client publication, not backend cancellation. Close retains selection, Back consumes previous selection, successful snapshots prune missing local IDs, and backend snapshot.selection is never a navigation source. These are client-only safety/detail corrections, not a new M2 API.
