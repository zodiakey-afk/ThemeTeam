## 4. 接口与数据边界

### 4.1 W01 只改实例生命周期

- 保留现有启动方式、HTTP 路径、正常请求/响应和 JSON 字段含义，不改变任何业务状态规则。
- HTTP 服务工厂应可接收显式 Store；未传入时只在实际创建服务时打开默认工作区，而非模块导入时加载。
- 每个服务绑定自己的 Store；测试不得用修改共享模块全局变量的方式伪装隔离。
- 临时数据清理只作用于本测试创建的目录。实际工作区内容最多用于只读完整性校验，不作为测试 fixture。

### 4.2 W02 保持正常路径兼容，拒绝错误输入

- 继续使用现有 `/api/state`、创建/状态变更、会议归档、保存/加载等原型接口；合法输入与正常成功响应保持兼容。
- 输入类型错误和未知引用分别返回稳定的 4xx 错误；资源状态冲突独立标识。确切 Schema、状态码、长度上限与错误格式在 G2 冻结，不能在实现中临时决定。
- 手动任务状态操作仍是原型的人工管理行为，不声称会执行任务；本批不引入真实运行状态机。
- 归档重复请求返回已有结果，不重复生成内容；不以新摘要静默覆盖旧归档。冲突及修订流程在正式契约中明确。
- 既有历史数据只兼容读取，不以此次安全修复批量改写历史审批字段或删除文档。新写入不再允许伪造人审；历史标记不构成工具执行授权。
- 旧 `seatId` 仍是原型房间引用，不在 W02 静默迁移成新座位 ID；校验目的地先于变更占用。正式固定工位持久化模型留给后续契约/迁移批次。

### 4.3 M1 是空间表现闭环，不是执行引擎

- 可读取真实工作区实体；正常 CRUD 通过 W02 加固后的接口调用。React DOM 与 Phaser 通过单一客户端状态入口同步，不各自维护另一份业务事实。
- 相机/选中/HUD 与行走插值属于客户端状态。首批座位锚点及角色动作是场景会话投影，不改写既有 `seatId` 的语义，不通过动画完成回调决定任务成功或会议结束。
- 演示移动/入座使用明确的演示会话；不向真实后台提交伪造的“开会”“开始模型执行”事件。刷新后从工作区事实重建，不承诺恢复每一帧动画位置。
- 首批会议桌只提供房间/既有记录入口及视觉预演；文件投放/审批可在分镜中体现，真实上传、审批执行和群聊能力不在 M1 偷渡实现。
- FastAPI、SQLite、outbox、WebSocket、LangGraph 的完整运行与恢复链路属于 M2；本批 API 请求失败须显示离线/错误，不声称已实现增量实时同步。
- 旧前端和旧数据保留至新入口通过验收；具体开发入口、静态构建路径、API adapter、依赖版本和测试脚本在 G2/G3 冻结，不提前覆盖用户正在使用的服务。

## 5. 首批 NFR 取值

沿用 requirements.md 第 10.3 节，不把真实运行、上传或迁移的后续指标套到本批模拟场景上。测试环境以执行时实际设备为准，必须记录 OS/CPU/GPU/内存、浏览器/Python/Node 版本、电源与 DPR；未实测不标通过。

| 验收 | 首批画像与阈值 | 证据 |
|---|---|---|
| 数据安全 | W01 的四轮测试后真实 JSON hash 不变；所有测试写入均位于独立临时目录；两个服务相互影响为 0 | 路径访问检查、两实例测试、进程/同进程复跑及前后 hash |
| W02 安全 | 越界文件读取 0、HTML 执行 0、无效命令产生业务变更 0、伪造审批成功 0 | 冻结安全用例、故障注入、独立评审 |
| M1 帧预算 | 1440x900、DPR 1/2、32x24 候选地图、20 人压力样本/8 人移动/5 气泡；目标 60fps，P95 帧间隔 <=20ms、P99 <=33ms | 预热 30 秒、采样 60 秒、重复 3 次，保留 trace/分位数；压力样本不写入真实团队 |
| M1 响应 | 200 个任务样本，选择/缩放/开关面板 30 次；输入反馈 P95 <=100ms，本地非模型命令 P95 <=300ms | 前端 marks 与请求时延记录 |
| M1 加载 | 本地资源冷缓存首屏可操作 <=3s，禁外网可打开已有数据 | 3 次冷缓存加载/无外网冒烟；资源随应用构建分发 |
| M1 可读与可达 | 390x844、1024x768、1366x768、1920x1080；长中文与长 ID 无互遮/不可达按钮，普通文字对比度 >=4.5:1 | 截图、DOM bounds、键盘流程、Canvas 非空/资产像素检查 |
| M1 稳定性 | 20 人场景 30 分钟，详情开关 100 次；第 10-30 分钟 GC 后 heap 增长 <=20%，不持续增加监听器 | heap/生命周期与资源统计 |

暂不适用：100 人多楼层验收、WS 断线重放、真实模型耗时、工具授权执行、文件解析/索引、SQLite 迁移。原因是对应运行能力不属于首批；替代检查为旧接口失败提示、临时 JSON 保存恢复、安全路径/文本案例和 M1 模拟场景。后续批次继续保留原 NFR，不删除这些需求。
