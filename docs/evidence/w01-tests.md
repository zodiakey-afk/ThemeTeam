# 环境与执行

Windows 11 build 26200，Python 3.14.7，PowerShell，工作目录 `C:\repos\ThemeTeam`。测试在随机本地端口、各例临时 Store 上执行，无第三方依赖。以下是工具输出整理，不是完整原始 CI 日志。

实现前新增 7 项隔离测试：旧实现 1 项通过、2 项失败、4 项错误（注入参数缺失、导入读取默认文件、工厂非延迟构造）。第一次沙箱执行还遭遇 Windows 临时目录清理权限问题，经工具批准沙箱外重跑得到上述干净失败结果。

实现后首轮 15/16 通过，发现 Windows 标准库允许地址复用导致第二次 bind 未失败。按冻结的端口冲突契约禁用服务地址/端口复用，未修改测试预期。

- 回归：原有 9 项 Store/API 功能测试保留业务断言，改为临时 fixture，不再依赖用户已保存数据。
